# 🎓 SmartEdu_Web – Frontend (Vite + React + TypeScript + Tailwind CSS)

Giao diện người dùng (Frontend) cho hệ thống **SmartEdu** – một nền tảng giáo dục thông minh hỗ trợ quản lý và tra cứu thông tin.
📍 GitHub: [MaiTrungChinhh/SmartEdu_Web](https://github.com/MaiTrungChinhh/SmartEdu_Web)

---

## 🚀 Công nghệ sử dụng

- ⚛️ React 19 + TypeScript
- ⚡ Vite
- 💨 Tailwind CSS
- 🌀 PostCSS + Autoprefixer

---

## ⚙️ Hướng dẫn cài đặt

### 1. Clone và cài đặt

```bash
git clone https://github.com/MaiTrungChinhh/SmartEdu_Web.git
cd SmartEdu_Web/frontend
npm install
```

### 2. Chạy dự án

npm run dev
